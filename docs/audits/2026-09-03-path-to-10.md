# Last Stop — Path to 10/10

- Remove filler/unverified proof.
- Resolve Unity 22 with public 19M+ total viewership.
- Put actual shipped copy forward where it is stronger evidence than a metric.
- Add provenance lines to hard results.

## Gate 2 — interaction/accessibility correction (autonomous now)
- Important text-navigation targets are 44px tall where practical.
- Focus remains visible and not hidden by fixed bars.
- ABOUT has no fake play control until a real reel exists.
- Sound defaults OFF on first visit.
- Animated campaign media gets reduced-motion static alternatives before production.

## Gate 3 — surface truth
- LANDING remains locked.
- WORK and MORE WORK remain current nine-case system.

## Gate 4 — rendered-pixel staging
At minimum: 1440×900, 1366×768, 1024×768, 430×932, 390×844.

Pass tasks:
1. Identify separate projects in ~3 seconds.
2. Open a named case in ~10 seconds.
3. Understand role + idea + evidence in a case in ~10–15 seconds.
4. Reach MORE WORK in one obvious action.
5. Keyboard through all primary links with visible focus.
6. Browser Back restores orientation.
7. Reduced-motion path loses no content.

## Gate 5 — final art + production media
- Replace merely-good images only where the ensemble or crop exposes a real weakness.
- Localize production images instead of hotlinking third-party servers.
- Extract static poster frames/fallbacks for GIF work.
- Preserve native campaign color: Last Stop frames the work; it does not recolor it.

## Gate 6 — launch engineering
- Per-case OG images.
- Canonical URLs.
- sitemap.xml + robots.txt.
- analytics only after privacy/measurement choice.
- Core Web Vitals field/preview check.
- final redirect check from existing Squarespace paths where needed.
- domain cutover only after cold-user tests pass.

## Definition of 10
10/10 is not `nothing left to tweak`. It means there is no known defect that would change a recruiter's understanding, trust, access to the work, or perception of authorship. Cosmetic alternate preferences can remain.
