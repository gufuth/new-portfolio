## Phase 1 — lock cinematic navigation language

### Landing → Work
- No generic web crossfade, zoom flight, game-like travel or decorative camera stunt.
- Click motivates one short photographic event in the Landing frame, then a cut through darkness / architectural occlusion into the booth view.
- The new view must feel like the next shot in the same film.
- Keep the transition brief enough that a recruiter never feels delayed.

### Work → More Work
- Read as a physical move to another booth / window bay inside the same diner.
- One restrained continuity cut.
- Rails / scene metadata carry orientation.
- A physical directional cue may supplement the rail, but cannot replace accessible navigation.

### Billboard → case
- Selected physical billboard gets a tiny local exposure / voltage lift.
- Selected campaign image becomes connective tissue.
- Short match cut / match dissolve from billboard face into case hero.
- Literal diner disappears once the case opens. The work gets the stage.
- Rails settle into editorial/evidence mode without decorative animation.
- Browser Back restores the exact originating billboard and focus.

### Reduced motion
- Use a clean cut instead of image choreography while preserving orientation and focus.

## Phase 3 — redesign the case-study master

The current cream template is not final. Use the existing Drive research direction: a dark editorial/evidence cut that belongs to Last Stop without becoming another themed room.

Prototype order:
1. Porsche first, because its evidence arc is strongest.
2. Cuervo immediately after, because its two-chapter relationship stress-tests the system.

### First-screen requirement
A cold reviewer should be able to answer at least three of these four after a very short glance:
1. What client / project is this?
2. What was the core problem or idea?
3. What did Ian own?
4. What is the strongest reason this case is worth continuing?

### Master anatomy
1. Transition hero, 72–85vh.
2. 15-second answer: problem/assignment, Ian’s role, idea, strongest verified proof.
3. The idea: one concise narrative plus one artifact that proves the organizing thought.
4. The work: three to five strongest outputs in an edited rhythm.
5. Words / decisions: shipped copy, VO, headlines, captions, scripts as live type where relevant.
6. Proof: verified outcomes / awards / public facts, blunt and sourced.
7. Role + credits: explicit ownership and collaborators.
8. Previous / All work / Next: visible plain navigation.

### Visual/type rules
- dark brown-black / black-green shell;
- dirty-cream main type;
- client work keeps native color;
- film-slate mono type is orientation metadata, not primary content type;
- body copy approx. 50–70 characters per line;
- no cards, dashboards, glass UI, case-file props or fake editorial distress;
- case-specific rhythm inside one recognizable system.

### Case-specific rhythm
- Nike: object/material-led.
- Virgin: wide atmospheric launch progression.
- Porsche: process-led, finished object → sketches/studio/build → proof.
- Selsun: short, film/comedy-led, real dialogue early.
- MoneyLion: system/scale/mechanic-led.
- Alita: editorial-engineering-led, fiction → real technology.
- Cuervo: two chapters, Playamar + Cristalino under one governing thought.
- Outdoor Voices: social/movement rhythm, live copy as proof.
- Atlantic: editorial motion with restrained GIF choreography.
