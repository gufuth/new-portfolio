## Gate 4 — Ambient life, extremely sparse
Ambient events are diegetic evidence that the place exists. They are not a feature layer.

Allowed family:
- Rare distant car pass: weak off-axis headlight contamination + dirty-glass glint; optional stereo road sound only when SOUND ON.
- One electrical imperfection: a single practical / fluorescent hesitation at most once per long visit, never a repeating loop.
- Optional tiny relay / ballast catch on the WORK click when sound is already enabled by user gesture.

Explicitly avoid:
- constant room-tone soundtrack,
- repeating flicker loops,
- thunder / rain / overt horror cues,
- visible cartoon cars,
- neon spectacle,
- multiple competing ambient tricks.

PASS WHEN: a user may miss the events entirely, but a longer visit feels subtly less static.
