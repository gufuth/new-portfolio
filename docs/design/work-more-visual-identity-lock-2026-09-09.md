# Work 1 / More Work visual identity lock

**Status:** active anti-drift law, 2026-09-09. This file supersedes older booth notes anywhere they conflict with later explicit user decisions.

## Core rule

**ONE FILM, TWO DIFFERENT SHOTS.**

Work 1 and More Work must unmistakably belong to the same Last Stop universe, but they must never share the same camera, framing, foreground architecture, window geometry, billboard geography, negative-space pattern, or exact spatial rhythm.

## Work 1 identity

Base family: Grok Booth 01.

Job: first iconic look out the diner window.

Preserve:
- angled interior diner view;
- booth / table / mug / sill foreground cues;
- broad road gap between viewer and work;
- five exterior billboard destinations;
- open horizontal roadside field;
- quiet dark ordinary roadside atmosphere;
- billboard group embedded in distance rather than packed into a wall.

### Hard rules

- **NO motel / hotel / Last Stop Motel sign in Work 1.**
- No motel Easter egg in Work 1.
- Do not import the More Work camera or stronger architectural frame.
- Do not tighten Work 1 until it resembles More Work.
- Do not change camera because a generation/edit is easier from another base.

## More Work / Work 2 identity

Base family: Gemini Booth 02.

Job: viewer has slid to another booth/window bay in the same diner.

Preserve:
- materially different angle from Work 1;
- stronger foreground architecture / diner framing;
- tighter, more compressed view through the window;
- different road-to-billboard relationship;
- more contained / isolated billboard group;
- distinct negative-space pattern and crop;
- same night, materials, film stock and practical-light logic as Landing and Work 1.

### Hard rules

- **Remove the current motel signage on the right side.**
- SCOOBA makes More Work a five-case environment and must become a full-size fifth physical billboard with the same apparent importance as the other four. It must not read as a smaller secondary destination or detached UI.
- Use the space released by removing the right-side motel sign to integrate the fifth board without crowding the frame.
- Motel signage is now optional, not required. If reintroduced, test only a faint, peripheral, worn clue in the dark upper-left area. A no-motel version is the control and may remain final.
- Preserve Gemini spatial difference. More Work is not a backup Work 1.
- Preserve asymmetry and believable architecture. Five boards must not become an evenly spaced poster gallery.
- One partial off-axis green spill/reflection may nod to the Landing WORK practical. Never show readable reflected WORK lettering.

## Shared law

Both pages share:
- Last Stop night universe;
- darkness as primary material;
- cheap ordinary diner/roadside materials;
- restrained local practical light;
- real road separation;
- physically integrated billboard faces;
- thin top/bottom rails;
- restrained interaction/accessibility behavior.

They do **not** share:
- camera;
- window geometry;
- foreground architecture/furniture composition;
- billboard spacing pattern;
- negative-space structure;
- exact visual rhythm.

## Pre-show identity gate

Before any Work or More Work generation/render is shown to Ian, compare it side by side with the approved references and answer:

1. Is this obviously the correct page, not the other Work page wearing different art?
2. Does Work 1 contain zero motel/hotel signage?
3. Does More Work preserve the distinct Gemini angle/composition?
4. Does More Work contain five equally legitimate physical project destinations, with SCOOBA the same apparent status as the others?
5. Is the right-side motel sign gone?
6. Are billboard geography and window framing materially different between the two pages?
7. Does the frame still belong to the same Last Stop film?

**Automatic reject:** fail #1, #2, #3, #4, or #5.

## Reference rule

Never generate a Work 1 or More Work visual from memory alone. Inspect/supply the approved page reference first. Every image-generation prompt must explicitly identify which page is being edited and must forbid importing the other page's camera/composition.
