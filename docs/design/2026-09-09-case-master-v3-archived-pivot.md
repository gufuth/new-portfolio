# Case master v3 — archived visual route

**Status:** archived reference, 2026-09-09. Not the active direction for the remaining case studies.

## Why it is being archived

Ian likes the visual craft, the proof-number emphasis, and the asterisked temporary metrics. But the current Porsche/Cuervo case system reads too modern, modular, and dashboard-like relative to the locked Landing North Star.

Objective audit:
- black / dirty-cream palette and thin rails create a surface-level bridge;
- the three-column proof rail, strict grid, crisp module boundaries, even spacing, and information-panel rhythm create product-dashboard/editorial-system associations;
- Landing is photographic, degraded, asymmetrical, spatial, low-microcontrast, and physically motivated;
- case master v3 is flat, precise, modular, and interface-like;
- therefore the bridge is insufficient. It belongs to the same color family, not yet the same film.

## Preserve

Do not delete:
- `case-master-v3.css`
- current Porsche v3 implementation
- current Cuervo v3 implementation
- temporary proof values / metric research
- honors treatment research
- screenshots and QA evidence

These may be reused later or mined for hierarchy/proof decisions.

## Keep from v3

- recruiter-first clarity;
- client/project -> idea -> Ian role -> proof -> work hierarchy;
- large, meaningful proof numbers;
- maximum three first-screen proof signals;
- asterisks on all unverified placeholder metrics;
- quiet exact award/honors language;
- one dominant hero image;
- strict avoidance of invented facts in production.

## Kill from v3 as active visual language

- dashboard-like stat rail;
- three equal proof columns as a default;
- excessive horizontal rules / module boundaries;
- overly crisp modern grid behavior;
- metadata density that competes with work;
- any case structure that could belong to a contemporary SaaS / design-system portfolio after swapping the colors.

## Next case-study requirement

The next direction must bridge from Last Stop narratively and materially without turning every case into a literal diner room or themed prop.

Target:
- feels like the next shot in the same film, not a new website template;
- darkness behaves spatially rather than as a flat UI background;
- media arrives in a cinematic sequence, one dominant beat at a time;
- asymmetry and negative space replace dashboard modularity;
- proof numbers become authored editorial/cinematic events, not KPI cells;
- client work retains native color;
- subtle grain, falloff, softened edges, imperfect blacks, and local practical-light residue may carry over from Landing;
- recruiter comprehension remains immediate.

## Governing sentence

**Keep the clarity. Lose the dashboard. Make the case feel cut from the same night as the diner.**
