Production task:
1. match the approved Work 2 letterforms to one real production font family once
2. verify the match against the Work 2 reference at real billboard size
3. use that exact same family, weight system, spacing and secondary-line treatment on both Work 1 and Work 2
4. secondary line must remain legible at rest; do not shrink/fade it to fit

## Non-negotiable cross-page rule

Work 1 and Work 2 use one billboard typography system. There are not two fonts.

The only variables allowed per board are text content and, if absolutely necessary, a small optical size adjustment to fit. Typeface family and hierarchy do not change.

## Rejection criteria

Reject any output that:
- changes the Work 1 camera or moves farther from the window
- lets a mullion cover a billboard
- changes the number of boards
- adds AI sheen, rain, synthetic crispness, or new lighting
- approximates the Work 2 type with a different-looking font
- makes the second line materially harder to read on one board than another
